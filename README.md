# Warda BOUBAKER - Portfolio Website

Welcome to my official portfolio website. It showcases my skills, projects, and services .

This portfolio features a responsive, modern design with sections that include an introduction, skills, services, portfolio, and contact information.

## Features

- **Responsive Design**: Fully responsive layout, ensuring an optimal viewing experience across different devices (desktop, tablet, and mobile).
- **Interactive Navbar**: Includes smooth scroll functionality to navigate the page seamlessly.
- **Smooth Animations**: JavaScript-driven animations for enhanced user experience.
- **Skills Section**: Displaying technical proficiencies such as Frontend, Backend, Tools & DevOps.
- **Portfolio Section**: Highlighting selected projects to showcase professional work.
- **Contact Section**: Users can contact Warda directly via email.

## Technologies Used

- **HTML5**: Structure of the website.
- **CSS3**: Styling for layout, typography, and colors.
- **Bootstrap 5**: Used for responsive grid and components.
- **JavaScript**: For interactivity (smooth scrolling, typing animation).
- **FontAwesome**: For icons across the website.
